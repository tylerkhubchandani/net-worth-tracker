# Net Worth Tracker

A personal net worth and portfolio tracker that runs entirely in the browser. I built it to learn how portfolio analytics, goal tracking, and long-term projections work by building them.

**Live site:** [tylerkhubchandani.com](https://tylerkhubchandani.com)

## What it does

- **Accounts and net worth:** track checking, savings, brokerage, retirement, other assets, and debts, with net worth over time.
- **Portfolio analytics:** allocation (stocks, bonds, cash, U.S. vs. international), concentration, and gain / loss by holding, account, or asset class.
- **Performance:** return over time using the Modified Dietz method, which adjusts for the timing of contributions.
- **Contributions:** one-time and scheduled deposits (monthly, twice a month, every two weeks, weekly) with monthly totals.
- **Goals and projections:** goals tied to net worth or an account, with a required-monthly-amount check, plus conservative, base, and optimistic projections adjusted for inflation.
- **Holdings import:** import positions from a brokerage CSV (Fidelity, Schwab, and Vanguard style exports).
- **Sample data:** a one-tap demo that never touches your own numbers.
- **Backup and restore:** download everything to a file and restore it later or on another device.

## How it works

Everything runs in the browser, and data is saved only on the device in local storage. Nothing is uploaded or sent to a server. Prices are entered by hand or imported from a CSV.

## Built with

A single-page web app in HTML, CSS, and JavaScript with no frameworks or build step, built with the help of an AI assistant.

## Run it locally

Open `index.html` in a browser. There is nothing to install.
